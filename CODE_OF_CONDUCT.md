# Code of Conduct

Nakeuri Foundry welcomes technical disagreement and critical review. Participation must remain professional, evidence-focused and respectful.

Contributors should discuss ideas and code rather than attacking people; avoid harassment, threats, discriminatory language and unwanted disclosure of private information; respect security embargoes and responsible-disclosure requests; and keep reviews focused on reproducible engineering concerns.

Project maintainers may edit, hide or remove contributions that violate these expectations and may restrict participation when necessary to protect contributors or the project.

If a conduct concern cannot be handled safely in a public issue, use the private contact mechanism published by the repository owner/organization once the GitHub repository is live.
