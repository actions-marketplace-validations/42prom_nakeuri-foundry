# Project Genome

The universal Foundry is stable; each product receives a project-specific Genome so generated applications are unique but internally coherent.

Directives: product, domain, design, UX, architecture, data, API, security, testing and delivery. Context tooling should load only directives relevant to the current task.

The Genome is governance, not decoration. Design tokens, interaction grammar, canonical ownership, state-management choice, API conventions and release policy are machine-readable and checked by guards.
