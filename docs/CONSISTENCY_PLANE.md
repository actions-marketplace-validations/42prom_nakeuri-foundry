# Consistency Plane

Consistency is enforced through three graphs and two guards:
- Capability Graph: one capability → one canonical owner.
- Invariant Registry: one business truth → explicit invariant + tests.
- Project Genome: one product/design/technical language.
- Duplicate Guard: detects duplicate capability ownership and semantic overlap candidates.
- Design Guard: flags raw styling outside the design system so agents reuse canonical components/tokens.
