# Evergreen Standards Radar

Every important engineering baseline has authority, source, version/snapshot, stability status, checked date, review interval and technology-radar ring.

Rings: ADOPT, TRIAL, ASSESS, HOLD.

Rules:
- strongest current proven practice > newest practice;
- draft/experimental material is not normative by default;
- stale source snapshots create an explicit warning;
- framework and security standards are revalidated on a cadence appropriate to their rate of change;
- project compatibility and complexity cost can override a global default with an ADR-backed exception.
