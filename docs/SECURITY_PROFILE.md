# High-Assurance Security Profile

Defense in depth: least-privilege agents and CI permissions, prompt/tool boundary protection, secret scanning, SAST/SCA, mobile static/runtime review, API authorization tests, dependency review, SBOM/provenance, signed/attested artifacts, environment approvals, staged rollout and rollback.

Third-party security skills are curated, pinned and vendored; they are knowledge modules, never unconditional executable authority.
