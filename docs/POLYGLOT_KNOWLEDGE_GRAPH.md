# Polyglot Knowledge Graph

V3 discovers framework/language surfaces in a monorepo and writes a deterministic graph. Specialist adapters normalize native contracts into a shared representation so the core can detect drift across OpenAPI/backend/client/database boundaries without pretending one parser understands every language natively.

The first deterministic normalized contract checks compare field presence, type, requiredness and nullability. Native semantic adapters can enrich the graph over time while preserving the same core contract.
