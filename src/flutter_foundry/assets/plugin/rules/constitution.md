# Nakeuri Flutter Foundry Constitution

- Project-local `PROJECT_RULES.md` is the technical source of truth.
- Evidence over memory.
- Smallest safe change wins.
- No unrelated refactors.
- No generic abstractions without multiple real use cases.
- Deterministic gates outrank reviewer prose.
- Writer cannot be sole approver.
- High-risk changes require independent review and human merge.
- Completion requires evidence, not "looks good".
